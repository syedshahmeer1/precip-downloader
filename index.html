Precipitate Counter

Drop in a BSE-SEM image. Get the particle count and sizes, the predicted mask, and a Fiji ROI zip to correct by hand.

Download for Windows Download for Mac
How to use
1. Unzip the download.
2. Windows: double-click PrecipitateCounter.exe. If SmartScreen warns, click More info, then Run anyway.
   Mac (first time only): in Terminal run xattr -dr com.apple.quarantine <path to the PrecipitateCounter folder> (drag the folder into Terminal), then double-click PrecipitateCounter.
3. Keep the window that opens. After 30-60 seconds your browser opens the app (or go to http://127.0.0.1:7860).
4. Drop in your images, enter the pixel size (nm/px) from the scale bar, press Count particles.

Everything runs on your own computer. Images are not uploaded anywhere. README.txt inside the download has the same steps.
